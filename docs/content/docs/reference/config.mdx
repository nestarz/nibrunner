The file `nibrunnerd install` writes and every `nibrunnerd start` reads. It is at
`/etc/nibrunner/config.toml` unless `NIBRUNNER_CONFIG` points elsewhere.
[Configuration](/docs/getting-started/configuration) is the guide; this page lists every key.
No key has a default: every key a section declares is required unless the table says otherwise,
and unknown keys are rejected.

A snapshot under `paths.snapshot_dir` outlives a host reboot when the host comes back on the same
kernel and CPU with the same Firecracker; otherwise `nibrunnerd start` removes it and the app's next
request boots it afresh.

An editor with TOML schema support (Even Better TOML for VS Code, taplo) validates and
autocompletes the file when its first line is:

```toml
#:schema https://raw.githubusercontent.com/ilbertt/nibrunner/main/deploy/config.schema.json
```
